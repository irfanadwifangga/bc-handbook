## Temuan

### P2 — indikasi mismatch pada label aksesibel search

Pada seluruh 52 state desktop, axe melaporkan `label-content-name-mismatch` dengan impact `serious`. Elemen: `button[data-open-modal]`.

Markup bawaan Starlight memberi `aria-label="Pencarian"`, sementara tombol juga menampilkan keycap Ctrl/K. Perilaku search sendiri berfungsi. Temuan otomatis ini perlu validasi manual atas perlakuan keycap sebagai bagian label, sebelum diputuskan sebagai pelanggaran WCAG atau memilih perbaikannya.

Lokasi integrasi: `astro.config.mjs:9`; source pemilik saat ini: `node_modules/@astrojs/starlight/dist/components/Search.astro:21`. Jangan mengedit dependency langsung. Calon penambahan nama shortcut saja belum menghilangkan hasil axe dalam simulasi; jangan menganggap perbaikan ini selesai sebelum retest.

### P2 — warna aside belum mengikuti token desain

Note dan caution pada Orientasi masih memakai palet bawaan Starlight. Contoh light: note berlatar `rgb(207, 212, 252)` dengan border `rgb(61, 80, 245)`; caution berlatar `rgb(252, 234, 197)`. Warna tersebut berada di luar palet `docs/DESIGN.md`.

Lokasi: `src/styles/custom.css`. Gunakan surface dan warna info/warning/success/danger yang sudah ada; pertahankan komponen Aside bawaan. Tidak diperlukan library UI baru.

### P2 — bayangan navigasi bertentangan dengan desain

Pagination masih memiliki layered shadow dari `--sl-shadow-md`, dan tombol menu mobile juga memakai shadow bawaan. Desain membatasi pengecualian shadow untuk dialog search.

Lokasi: `src/styles/custom.css`; source pemilik pagination: `node_modules/@astrojs/starlight/dist/components/Pagination.astro:49`. Hilangkan shadow lewat CSS proyek pada elemen terkait, sambil mempertahankan outline fokus.

### P2 — kolom pertama tabel materi memotong kata terlalu pendek

Pada mobile, tabel Orientasi dapat memecah istilah seperti Environment, Inventory, dan Personalize di tengah kata. Halaman tidak overflow, tetapi label menjadi lebih sulit dipindai.

Penyebab: `overflow-wrap: anywhere` diwariskan dari `.sl-markdown-content`, sedangkan pengecualian kolom pertama baru berlaku untuk `.bc-cheatsheet`. Lokasi: `src/styles/custom.css:109` dan `src/styles/custom.css:132`.

Usulan: perluas aturan kolom pertama ke tabel konten secara umum; pertahankan scroll di dalam tabel. Calon CSS diperiksa dalam browser terisolasi, tanpa diterapkan pada source.

### Catatan kecil dan status konten

- Label tema Otomatis terlihat terpotong pada desktop 1280px. Komponen ThemeSelect bawaan memiliki catatan bahwa ukuran select belum menyesuaikan semua bahasa; perlu pemeriksaan ukuran kontrol bila dirapikan.
- Teks footer tampak menyatu pada bagian “cekMicrosoft Learn”; beri spasi eksplisit bila memperbaiki `src/components/Footer.astro:7`.
- Basic, Intermediate, Expert, latihan, glosarium, dan referensi masih memiliki konten kerangka sesuai fase. Ini bukan error layout; jangan menganggap materi sudah lengkap.
- Empat direktori track Expert belum mempunyai halaman indeks dan mengembalikan 404. Kedua URL acak juga benar-benar mengembalikan HTTP 404. `/404.html` langsung dapat diakses sebagai file statis dengan HTTP 200; ini berbeda dari respons URL yang tidak ditemukan.
- Halaman 404 tampil, satu H1, tanpa overflow. Tautan brand dan search tetap tersedia; body belum memiliki tautan pemulihan khusus ke beranda.

## Hasil yang lulus

- Menu mobile membuat konten utama inert saat terbuka. Tidak adanya atribut aria-expanded eksplisit tidak otomatis dianggap bug karena komponen memakai Popover API.
- Reduced motion menghasilkan durasi transisi 0s.
- Tombol copy menyalin tiga shortcut yang sesuai.
- Tujuh PDF masing-masing satu halaman A4; hasil cetak dan artefak tersimpan lokal.
