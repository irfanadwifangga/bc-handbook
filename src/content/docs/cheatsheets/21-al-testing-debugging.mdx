Bahasa AL belum tersedia pada highlighter situs; contoh ditampilkan sebagai teks biasa.

| Elemen Pengujian | Tipe / Deskripsi | Peran Utama |
| --- | --- | --- |
| Subtype = Test | Properti Codeunit | Menandai unit tes; isolasi transaksi otomatis |
| [Test] | Atribut Prosedur | Menandai metode eksekusi pengujian |
| [HandlerFunctions] | Atribut Delegasi UI | Menangani Confirm, Message, ModalPage tanpa memblokir runner |
| TestPage | Tipe Data Simulasi | Membuka dan menguji interaksi field/action pada halaman |
| Library - Assert | Codeunit Pustaka | Validasi kondisi nilai (Assert.AreEqual, Assert.IsTrue) |
| Feature Telemetry | Modul Sistem | Mengirim telemetri terstruktur ke Application Insights |

```text
// Kerangka Test Codeunit
codeunit 50205 "MYP Quick Test"
{
    Subtype = Test;
    TestPermissions = Disabled;

    [Test]
    [HandlerFunctions('ConfirmHandler')]
    procedure TestVendorValidation()
    var
        Vendor: Record Vendor;
    begin
        // Given: Vendor baru
        Vendor.Init();
        Vendor."No." := 'V-TEST';
        Vendor.Insert();
        // When & Then: Panggil validasi dan pastikan tidak error
    end;

    [ConfirmHandler]
    procedure ConfirmHandler(Question: Text[1024]; var Reply: Boolean)
    begin
        Reply := true;
    end;
}
```

| Diagnosa & Telemetri | Metode / Kueri | Fungsi |
| --- | --- | --- |
| Breakpoint | VS Code (F5 / F9) | Menelusuri baris kode dan variabel di sandbox |
| Snapshot Debug | launch.json "snapshot" | Menangkap call stack sesi tanpa menghentikan user |
| AL Profiler | .alcpuprofile | Mengukur durasi komputasi dan menemukan hotspot |
| LogUsage / LogError | Feature Telemetry | Mencatat siklus hidup fitur dan galat operasional |

```text
// Contoh KQL Application Insights:
traces
| where timestamp > ago(24h)
| where customDimensions.eventId == '0000MYE'
| project timestamp, customDimensions.alCallerCodeunit, message, customDimensions.ErrorCode
| order by timestamp desc
```
