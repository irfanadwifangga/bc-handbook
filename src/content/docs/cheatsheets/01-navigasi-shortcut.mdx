Pakai di sandbox CRONUS. Shortcut berikut untuk Windows; role, bahasa, keyboard, dan browser dapat memengaruhi hasil.

| Kebutuhan | Cara cepat |
| --- | --- |
| Cari halaman, report, atau action | `Alt+Q` membuka Tell Me. |
| Periksa page dan source table | `Ctrl+Alt+F1`; alternatif Help & Support → Inspect pages and data. |
| Ganti company | `Ctrl+O`; cek juga environment aktif. |
| Buka My Settings | `Alt+T`; periksa Company, Role, dan Language. |
| Tampilkan/sembunyikan FactBoxes | `Alt+F2`. |
| Filter record | Buka panel filter; pilih field dan nilai. Bersihkan filter setelah selesai. |
| Atur kolom/field | Settings → Personalize → atur field yang diizinkan → Done. |
| Ekspor untuk dibaca | Open in Excel; perubahan di file tidak dipublikasikan kembali ke BC. |
| Ubah lewat Excel | Edit in Excel lalu Publish, hanya bila halaman, add-in, dan izin mendukung. |

**Hindari salah klik:** Open in Excel dan Edit in Excel berbeda. Jangan Publish perubahan data nyata sebagai latihan.

```text title="Shortcut Windows"
Alt+Q        Tell Me
Ctrl+O       Ganti company
Ctrl+Alt+F1  Page Inspection
```
