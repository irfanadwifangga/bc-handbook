**Target:** CRONUS sandbox. Prefix SaaS: `https://api.businesscentral.dynamics.com/v2.0/<TENANT_ID>/<ENV>/api/v2.0`. Pilih company GUID dari GET companies.

| Operasi | Pola / perhatian |
| --- | --- |
| Auth | S2S: client credentials, scope BC .default; consent Entra + app Enabled/permission BC |
| Baca | GET companies; GET companies(id)/customers |
| Query | $filter menyaring; $select kolom; $orderby urutan; $expand relasi yang didukung |
| Paging | Ikuti @odata.nextLink; top membatasi total hasil, bukan paging manual |
| Draft | POST companies(id)/purchaseInvoices; nested purchaseInvoiceLines untuk deep insert |
| Ubah | PATCH purchaseInvoices(id), If-Match berisi ETag spesifik dari GET |
| Posting | POST purchaseInvoices(id)/Microsoft.NAV.post; sukses 204 tanpa body |
| 401 / 403 | Periksa token/audience/expiry atau izin app/objek/company |
| 412 / 429 | Baca ulang dan review konflik / cooldown serta retry terbatas |
| Timeout write | Cari hasil di BC dahulu; jangan replay POST otomatis |

```text
$filter=displayName eq 'MYP DEMO'
$select=id,number,displayName&$top=50&$orderby=number
```

**Kontrol:** jangan log token; validasi host nextLink; simpan ID write; review pajak/tanggal/permission; rekonsiliasi ledger setelah posting. Contoh belum dijalankan di BC. [Materi dan latihan](/03-expert/integrasi-api/).
