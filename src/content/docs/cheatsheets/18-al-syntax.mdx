Bahasa AL belum tersedia pada highlighter situs; contoh ditampilkan sebagai teks biasa.

| Pilihan | Gunakan untuk |
| --- | --- |
| Integer / Decimal | Hitungan bulat / pecahan |
| Code / Text | Kode bisnis ternormalisasi / teks bebas |
| Boolean / Date / DateTime | Kondisi / tanggal / waktu |
| Enum / List / Dictionary | Pilihan bernama / urutan nilai / pasangan key-value |
| Label | Teks aplikasi yang dapat diterjemahkan |
| local / internal | Scope procedure di objek / module, bukan izin data |
| parameter var | Perubahan ke nilai caller; gunakan jika disengaja |
| if/case/repeat/for | Cabang dan pengulangan yang dibatasi |
| condition ? a : b | Ternary pada runtime yang mendukung; if/else tetap cukup |
| Message/Error/Confirm | Informasi / hentikan operasi / keputusan user interaktif |
