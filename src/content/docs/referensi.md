Kumpulan tautan referensi resmi Microsoft dan repositori rujukan untuk mendalami Business Central, arsitektur teknis, dan standar pengembang.

## Dokumentasi Resmi Microsoft Learn

- **[Business Central Documentation Hub](https://learn.microsoft.com/en-us/dynamics365/business-central/)** — Pusat dokumentasi pengguna bisnis, fungsional, dan fungsionalitas modul standar.
- **[Developer and IT Pro Documentation](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/)** — Panduan arsitektur teknis, runtime AL, integrasi, dan deployment.
- **[REST API v2.0 Reference](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/api-reference/v2.0/)** — Spesifikasi endpoint resmi v2.0 untuk Customers, Vendors, Invoices, Items, dan metadata.
- **[Automation APIs Reference](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/administration/automation-apis-using-s2s-authentication)** — Endpoint khusus otomatisasi manajemen tenant, ekstensi, dan salin company.
- **[Deprecated Features Platform](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/upgrade/deprecated-features-platform)** — Catatan fitur usang platform termasuk penghentian SOAP dan OData halaman Microsoft.
- **[Choosing Runtime Version](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-choosing-runtime)** — Tabel kesesuaian antara versi aplikasi Business Central dan runtime compiler AL.

## Repositori GitHub Resmi

- **[microsoft/BCTech](https://github.com/microsoft/BCTech)** — Contoh kode resmi integrasi OAuth2, skrip telemetri Application Insights (KQL), dan sampel performa.
- **[microsoft/AL-Go](https://github.com/microsoft/AL-Go)** — Template repositori GitHub Actions standar industri untuk CI/CD kompilasi dan pengujian ekstensi PTE maupun AppSource.
- **[microsoft/ALAppExtensions](https://github.com/microsoft/ALAppExtensions)** — Sumber terbuka modul lokalisasi dan aplikasi sistem bawaan Business Central.

## Panduan Sertifikasi Microsoft

- **[Study Guide Exam MB-800: Microsoft Dynamics 365 Business Central Functional Consultant](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/mb-800)** — Panduan kompetensi analisis kebutuhan bisnis, konfigurasi sistem, dan operasional finansial/rantai pasok.
- **[Study Guide Exam MB-820: Microsoft Dynamics 365 Business Central Developer](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/mb-820)** — Silabus keahlian pemrograman AL, objek sistem, event handling, integrasi API, dan siklus hidup ekstensi.

## Komunitas & Standar Praktik Terbaik

- **[AL Guidelines (alguidelines.dev)](https://alguidelines.dev/)** — Panduan gaya penulisan kode, penamaan objek, konvensi event, dan praktik terbaik komunitas AL global.
- **[Microsoft AI at Work Roadmap](https://learn.microsoft.com/en-us/dynamics365/business-central/)** — Roadmap pembaruan fitur platform, integrasi Copilot, dan autonomous agents pengganti Release Plans tradisional.
