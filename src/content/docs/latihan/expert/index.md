Latihan Business Analysis tersedia untuk data demo CRONUS di sandbox. Mulai dari [materi Track 3A](/03-expert/business-analysis/).

- [E1 — Process mapping](./e1-process-mapping/) — as-is/to-be, tiga pain point dan review perubahan.
- [E2 — Gap-fit analysis](./e2-gap-fit/) — BRD ringkas, sepuluh kebutuhan, matriks dan draft spesifikasi.
- [E3 — UAT planning dan execution](./e3-uat/) — lima test script dengan actual result serta bukti praktik.

Gunakan [studi kasus draft](/03-expert/business-analysis/09-studi-kasus/) sebagai contoh; klasifikasi fit dan hasil UAT belum diverifikasi pada tenant. Kriteria lulus bukan klaim latihan sudah dijalankan. Panduan Integrasi & API juga tersedia:

- [E4 — API baca](./e4-api-baca/) — S2S, query, paging dan permission.
- [E5 — API tulis dan posting](./e5-api-tulis/) — draft, ETag, konflik/retry dan bukti posting sandbox.
- [E6 — Custom API page](./e6-custom-api/) — entity demo, kompilasi pemilik dan CRUD.
- [Capstone — Spreadsheet-to-BC](./capstone-spreadsheet-to-bc/) — BRD, gap-fit, setup, importer CSV dan UAT.

Mulai dari [Track 3B](/03-expert/integrasi-api/). Kode AL belum dikompilasi; tes client mock tidak membuktikan koneksi atau transaksi BC berhasil.
