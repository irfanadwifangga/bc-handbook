Jalur tingkat lanjut untuk pengembang AL yang mencakup keandalan aplikasi, pengujian terotomatisasi, diagnosa telemetri, manajemen siklus hidup dan upgrade, serta pipeline otomatisasi rilis.

## Modul pembelajaran

- [AL-3.1 Testing otomatis dan AL Test Tool](./01-testing/) — Subtype Test, TestPage, HandlerFunctions, library test standar, dan isolasi pengujian.
- [AL-3.2 Debugging tingkat lanjut dan diagnosa](./02-debug-diagnosa/) — Snapshot debugging, profiler, Feature Telemetry, serta kueri KQL di Application Insights.
- [AL-3.3 Siklus hidup dan pola upgrade](./03-siklus-hidup-upgrade/) — Upgrade codeunit, upgrade tags, tata kelola Obsolete, dan strategi transisi versi wave.
- [AL-3.4 Kualitas kode dan analyzer](./04-kualitas-kode/) — CodeCop, UICop, PerTenantExtensionCop, AppSourceCop, custom ruleset, dan pedoman komunitas.
- [AL-3.5 Pemrosesan background dan manajemen performa](./05-performa-background/) — Set-based operation, isolasi locking, Task Scheduler, Job Queue, dan Page Background Task.
- [AL-3.6 Praktik DevOps dan CI/CD](./06-devops/) — Git branching, template AL-Go for GitHub, BcContainerHelper, dan pipeline multi-lingkungan.
- [AL-3.7 PTE vs AppSource](./07-pte-vs-appsource/) — Batasan fungsional Per-Tenant Extension dan persyaratan kelayakan AppSource.
- [AL-3.8 Eksplorasi AI dan agent di AL](./08-ai-di-al/) — Ekstensibilitas Copilot, prompt dialog, pemanggilan Azure OpenAI, dan batasan operasional.
