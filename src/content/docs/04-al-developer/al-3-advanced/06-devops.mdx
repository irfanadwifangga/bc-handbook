## Tujuan belajar

Menyusun alur kerja version control Git, mengonfigurasi otomatisasi CI/CD menggunakan AL-Go for GitHub, memahami kontainerisasi build dengan BcContainerHelper, dan mengelola terjemahan XLIFF.

## Konsep singkat

Manajemen kode AL modern mengandalkan Git dengan repositori yang terisolasi dari artefak biner (`.alpackages/`, `.app`). Microsoft menyediakan AL-Go for GitHub, yaitu template workflow GitHub Actions siap pakai untuk mengotomatisasi kompilasi, eksekusi test runner, verifikasi analyzer, dan publikasi ekstensi ke lingkungan Business Central secara konsisten.

Untuk eksekusi build dan pengujian yang dapat direproduksi, pipeline sering memanfaatkan BcContainerHelper yang memutar kontainer Docker Business Central secara otomatis. Selain itu, fitur lokalisasi bahasa dikelola melalui file terjemahan standar XLIFF (`.xlf`).

> ⚠️ Verifikasi: Pipeline AL-Go memerlukan konfigurasi GitHub Secrets (seperti `AuthContext` atau kredensial service principal Azure) dan runner dengan kapasitas komputasi yang memadai untuk menjalankan kontainer build.

## Langkah di BC

1. Inisialisasi repositori Git dan pastikan file `.gitignore` mengabaikan folder `.alpackages`, file `.app`, cache VS Code, dan file kredensial `launch.json`.
2. Aktifkan pembuatan file terjemahan otomatis pada manifest `app.json` dengan menambahkan `"features": [ "TranslationFile" ]`.
3. Buat repositori baru menggunakan template resmi `AL-Go-PTE` dari GitHub Microsoft untuk ekstensi per-tenant.
4. Daftarkan rahasia otentikasi target environment di pengaturan GitHub Secrets (menggunakan identitas Azure AD / App Registration berizin).
5. Buat pull request pada branch utama untuk memicu pipeline otomatis: validasi kompilasi kode, eksekusi test codeunit, dan pemeriksaan CodeCop.
6. Pantau artefak rilis (`.app`) yang dihasilkan otomatis oleh job CI dan verifikasi log status pengujian sebelum mengizinkan penggabungan kode (merge).

## Cheat box

<CheatBox>

- Abaikan folder .alpackages dan file .app di dalam .gitignore.
- Gunakan template AL-Go for GitHub untuk standarisasi CI/CD.
- Jalankan kompilasi dan suite pengujian otomatis pada setiap PR.
- Manfaatkan BcContainerHelper untuk lingkungan build deterministik.
- Aktifkan fitur TranslationFile untuk ekspor string ke format XLIFF.
- Amankan kredensial deployment melalui GitHub Secrets tersanitasi.

</CheatBox>

## Kesalahan umum

:::danger[Kesalahan umum]
Menyimpan file biner package `.app` atau kredensial tenant (client secret / username password) ke dalam repositori Git publik maupun privat.
:::
