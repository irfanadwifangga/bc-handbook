## Cara Memakai Handbook

- **Mulai dari mana:** Pelajari secara berurutan mulai dari [Level 0 Orientasi](./00-orientasi/) dan [Level 1 Basic](./01-basic/) untuk memahami operasional ERP dan konsep posting buku besar sebelum masuk ke konfigurasi.
- **Pilih fokus kerja:** Dalami [Track Business Analysis](./03-expert/business-analysis/) untuk kebutuhan analisis fungsional/UAT, [Track Integrasi & API](./03-expert/integrasi-api/) untuk otomasi data, atau ikuti [Jalur AL Developer](./04-al-developer/) jika membuat ekstensi custom.
- **Rujukan cepat saat bekerja:** Buka menu [Cheatsheets](./cheatsheets/) harian untuk memverifikasi alur dokumen, matriks posting groups, shortcut Tell Me, atau checklist persiapan rilis.
- **Versi yang diverifikasi:** Seluruh materi disusun dan diverifikasi terhadap fitur **Business Central 29.x (2026 release wave 2)**.

## Prasyarat Lingkungan Belajar

- **Gunakan Sandbox Demo:** Semua latihan dan eksperimen wajib dijalankan di environment **Sandbox** dengan company demo **CRONUS**.
- **Larangan Data Nyata:** Dilarang menggunakan kredensial produksi, tenant ID privat, atau data transaksi pelanggan nyata dalam latihan integrasi maupun repositori kode.
