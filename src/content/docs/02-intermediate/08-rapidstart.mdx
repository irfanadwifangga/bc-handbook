## Tujuan belajar

Rencanakan migrasi setup ke company baru dengan tahapan review yang jelas. Semua perubahan operasional contoh dilakukan sendiri oleh pembelajar pada CRONUS sandbox.

## Konsep singkat

Worksheet mengelompokkan tabel dan pekerjaan; Package membawa field/data; Template memberi default; Questionnaire mengumpulkan jawaban setup. RapidStart ditujukan untuk inisialisasi company, bukan alat impor rutin pada company produksi. Import ke package belum sama dengan Apply ke tabel tujuan.

## Langkah di BC

1. Buat company tujuan baru di sandbox; samakan versi BC, schema dan extensions sumber/tujuan. Salin package default, jangan ubah aslinya.
2. Di Configuration Worksheet, susun tabel setup kecil, lalu Assign Package. Periksa relasi secara manual; Get Related Tables tidak menjamin semua relasi bersyarat ikut.
3. Pada package, pilih field melalui Include Field dan urutkan dependensi. Hindari tabel posted ledger; jangan menonaktifkan validation agar data bermasalah lolos.
4. Export Excel atau .rapidstart; isi data demo. Import kembali, tinjau Package Errors lalu Validate sebelum Apply Package ke company baru.
5. Siapkan satu template default Customer dan questionnaire berisi tiga pertanyaan. Review format jawaban secara manual sebelum Apply Answers.
6. Cocokkan hasil pada setup pages. Untuk migrasi master lewat Edit in Excel, lihat M7; untuk statement bank/Data Exchange Definition, lihat modul Bank. Keduanya bukan tahap yang otomatis dijalankan package.

## Cheat box

<CheatBox>

- Worksheet: rencana.
- Package: field dan data.
- Template: default record.
- Questionnaire: jawaban setup.
- Import → Validate → review → Apply.
- Company baru, versi/schema sesuai.

</CheatBox>

## Kesalahan umum

:::danger[Kesalahan umum]
Apply ke company yang salah, mengimpor ledger terposting, mengabaikan dependensi relasi, atau menganggap questionnaire otomatis memvalidasi semua format jawaban.
:::
