## Tujuan belajar

Tinjau akses efektif berdasarkan license, permission sets dan company scope. Semua perubahan operasional contoh dilakukan sendiri oleh pembelajar pada CRONUS sandbox.

## Konsep singkat

License memberi batas entitlement; permission sets menentukan akses dalam batas itu. Role/profile mengatur tampilan dan bukan pengamanan data. Untuk target BC 29.x, User Groups dibahas sebagai istilah legacy; gunakan Security Groups untuk pengelolaan kelompok. Permission set dapat menyertakan set lain, sehingga pemeriksaan tidak berhenti pada satu assignment.

## Langkah di BC

1. Di sandbox, inventaris user uji, license, company scope dan tugas yang benar-benar dibutuhkan. Jangan menyalin tenant/user nyata ke catatan publik.
2. Buka Permission Sets dan tinjau Read/Insert/Modify/Delete/Execute, termasuk included/excluded permissions. Kelompok permission set bukan alasan mengasumsikan halaman bernama Permission Set Group tersedia.
3. Tinjau Security Groups dan assignment langsung user. Perhatikan bahwa gabungan assignment dapat memberi akses lebih luas.
4. Gunakan tampilan effective permissions pada user uji untuk memeriksa tabel dan company sasaran. Microsoft 365 access melalui Teams bukan pengganti otomatis license operasional BC.
5. Uji user auditor: baca ledger yang disetujui harus berhasil; mengubah master data atau posting harus ditolak. Gunakan sesi user auditor sendiri, bukan impersonasi kesimpulan dari SUPER.
6. Dokumentasikan izin minimum dan exception yang ditemukan. Hindari pemberian SUPER agar tes cepat lulus.

## Contoh praktik

- **Kondisi awal** — Auditor demo perlu membaca ledger dan tidak diberi tugas posting.
- **Langkah** — Bandingkan akses baca dan percobaan posting dengan user uji yang memiliki assignment terbatas.
- **Hasil yang diharapkan** — Kamu punya bukti akses baca dan penolakan posting dalam cakupan company uji.

## Kesalahan umum

:::danger[Kesalahan umum]
Menyembunyikan tombol sebagai satu-satunya kontrol akses, menilai satu permission set tanpa assignment lain, atau menganggap semua Microsoft 365 user bisa posting BC.
:::
