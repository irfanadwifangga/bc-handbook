## Tujuan belajar

Baca data yang diperlukan tanpa melewatkan halaman hasil atau mengambil kolom berlebihan.

## Konsep singkat

Filter menyaring record; select membatasi kolom; expand memuat navigasi terkait. Top membatasi hasil, bukan ukuran halaman untuk ekspor lengkap. Respons dapat memberi @odata.nextLink: ikuti URL server itu, tanpa membangun skiptoken sendiri. Paging bukan snapshot transaksi; rekonsiliasi diperlukan bila data berubah saat pembacaan.

## Langkah di BC

1. Mulai dengan GET companies. Pilih ID berdasarkan company demo yang kamu verifikasi di UI.
2. Baca customers dengan parameter di bawah. Ganti MYP DEMO dengan nama customer latihan yang ada; hasil kosong juga hasil sah.
3. Untuk ekspor lengkap, hapus batas top dan minta Prefer: odata.maxpagesize=100. Ikuti nextLink sampai habis; jangan menambahkan parameter awal lagi ke URL lanjutan.
4. Validasi nextLink tetap HTTPS pada host dan environment yang diizinkan sebelum menyertakan token. Simpan checkpoint hanya setelah batch berhasil diproses.
5. Uji nama yang mengandung apostrof: escape literal OData dengan menggandakan apostrof, lalu biarkan library meng-encode query. Jangan merangkai masukan bebas sebagai ekspresi.
6. Gunakan expand hanya untuk relasi yang ada pada resource. Deep patch koleksi tidak didukung; OR lintas field dan lambda juga memiliki batas pada BC.

```python
params = {
    "$filter": "displayName eq 'MYP DEMO'",
    "$select": "id,number,displayName",
    "$top": "50",
    "$orderby": "number",
}
# Client contoh di examples/api/bc_client.py
for row in api.rows(f"companies({company_id})/customers", params):
    process_demo_row(row)  # fungsi milik latihan; jangan log data nyata
```

## Contoh praktik

- **Kondisi awal** — Mock mengembalikan dua halaman data customer dengan nextLink.
- **Langkah** — Minta id dan nama, ikuti nextLink dari server, lalu bandingkan kumpulan ID hasilnya.
- **Hasil yang diharapkan** — Semua ID sintetis diproses sekali dan query awal tidak ditempel ulang ke nextLink.

## Cheat box

<CheatBox>

<CheatGroup label="Batas hasil">

- **Select** hanya kolom yang perlu.
- **Top** membatasi hasil.

</CheatGroup>

<CheatGroup label="Paging">

- Ikuti **nextLink** dari server.
- Jangan buat **skiptoken** sendiri.

</CheatGroup>

<CheatGroup label="Validasi hasil">

- Escape literal dan **encode URL**.
- Rekonsiliasi hasil pembacaan.

</CheatGroup>

</CheatBox>

## Kesalahan umum

:::danger[Kesalahan umum]
Menganggap halaman pertama adalah seluruh data, memakai top/skip sebagai paging manual, atau meneruskan bearer token ke host dari nextLink tanpa validasi.
:::
